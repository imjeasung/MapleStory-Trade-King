# 메이플스토리 무역왕 AI 조언기

메이플스토리의 '무역왕' 이벤트에서 최적의 선택을 도와주는 Q-러닝 기반의 조언기입니다. 목표는 **솔 에르다 조각** 보상을 최대로 받는 것입니다.
조난을 당하는 일을 막기 위해 만들었습니다.

## 프로젝트 목표

무역왕 이벤트는 매 순간 진행할지, 멈추는 선택 사이에서 딜레마에 빠집니다. 하지만 인간의 욕심으로 인하여 늘 똑같은 실수를 반복하죠. 이 프로젝트는 Q-러닝(Q-Learning) 강화학습 알고리즘을 사용하여, 주어진 상황(현재 단계, 남은 교역 횟수)에서 어떤 선택이 최선의 선택인지를 강화학습을 통해서 조언을 받고자 합니다.

## 사용 기술

- **언어**: Python
- **핵심 라이브러리**:
  - `Flask`: 간단한 웹 UI를 제공하여 사용자가 쉽게 조언을 얻을 수 있도록 합니다.
  - `NumPy`: Q-테이블 계산 및 확률 기반의 환경 시뮬레이션을 위해 사용됩니다.
  - `Matplotlib`: 학습 과정과 결과를 시각화하기 위해 사용됩니다.
- **알고리즘**: Q-Learning (강화학습)

## 파일 구조

```
.
├── app.py              # Flask 웹 애플리케이션 실행 파일
├── agent.py            # Q-러닝 에이전트 클래스
├── environment.py      # 무역왕 게임 환경 시뮬레이터
├── train.py            # AI 모델(Q-테이블) 학습 스크립트
├── evaluate.py         # 학습된 AI 성능 평가 및 테스트 스크립트
├── q_table.pkl         # 학습된 Q-테이블 데이터 파일
├── templates
│   └── index.html      # 웹 UI를 위한 HTML 템플릿
└── README.md           # 프로젝트 설명 파일
```

## 사용 방법

### 1. 웹으로 실행

미리 학습된 모델을 통해 바로 최적의 행동을 추천받을 수 있습니다.

**요구사항**: `Flask` 라이브러리가 설치되어 있어야 합니다.
```bash
pip install Flask
```

**실행**:
```bash
python app.py
```
위 명령어를 실행한 후, 웹 브라우저에서 `http://127.0.0.1:5000` 주소로 접속하세요. 현재 레벨과 남은 교역 횟수를 입력하면 AI가 'UP' 또는 'STOP'을 추천해줍니다.

### 2. 모델 재학습 및 평가 (선택 사항)

모델을 직접 학습시키거나 성능을 테스트하고 싶을 경우 아래 스크립트를 사용하세요.

**요구사항**: `tqdm`, `matplotlib` 라이브러리가 필요합니다.
```bash
pip install tqdm matplotlib
```

**학습**:
```bash
python train.py
```
이 스크립트는 `q_table.pkl` 파일을 생성/업데이트하며, 학습이 완료되면 결과 그래프를 보여줍니다.

**평가**:
```bash
python evaluate.py
```
학습된 모델의 성능을 통계적으로 평가하거나, AI의 추천을 받으며 직접 게임을 플레이해볼 수 있습니다.
